# Surface brief: dashboard Overview

Mode: Operate. Visitor: a Channel operator (independent writer or small team), daily or weekly, desktop first, also 390px.

Job: on day one, reach a first send in about ten minutes; afterwards, know at a glance whether the last Broadcast landed and what to do next.

States: first run (no domain or partial setup), ready (setup done, nothing sent yet), established (Broadcasts sent). Each must look finished.

Constraints: Indigo tokens only; standard web controls; vocabulary per docs/vocabulary.md; synthetic data labelled until the API exists; no invented claims.

Unresolved: real data wiring arrives with Phases 1–2; router choice (D8).
